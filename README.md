# rclone-personal

Personal-use OAuth client for syncing my own Google Drive to my own computer with [rclone](https://rclone.org).

- Owner and sole user: Adhistira Naufal (adhistira.naufal@gmail.com)
- Not a public application. No one else is meant to sign in to it.
- Requested access: Google Drive (`drive` scope), to read and write the owner's own files.

See [PRIVACY.md](PRIVACY.md) for the privacy policy.
